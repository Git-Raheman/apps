# Real-Time Chat App with Docker

A real-time chat application built with React, Node.js (Socket.io), Redis, and Nginx.

## How to run

1. Ensure Docker and Docker Compose are installed.
2. Navigate to the `02-chat-app` directory.
3. Run the following command:

```bash
docker-compose up --build
```

The application will be available at [http://localhost:81](http://localhost:81).
