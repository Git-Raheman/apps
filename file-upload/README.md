# File Upload App with Image Resizing

A full-stack application built with React, Node.js (Multer + Sharp), MinIO, and Nginx.

## How to run

1. Ensure Docker and Docker Compose are installed.
2. Navigate to the `04-file-upload` directory.
3. Run the following command:

```bash
docker-compose up --build
```

The application will be available at [http://localhost:83](http://localhost:83).
MinIO Console: [http://localhost:9001](http://localhost:9001) (User: admin, Pass: password)
