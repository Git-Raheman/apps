# Blog App with User Auth

A full-stack blog application built with React, Node.js (JWT Auth), PostgreSQL, and Nginx.

## How to run

1. Ensure Docker and Docker Compose are installed.
2. Navigate to the `03-blog-auth` directory.
3. Run the following command:

```bash
docker-compose up --build
```

The application will be available at [http://localhost:82](http://localhost:82).
